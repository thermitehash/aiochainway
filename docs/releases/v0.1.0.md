# v0.1.0: First release: UR4 TCP client, UDP listener, presence, CLI

First release of `aiochainway`, an async, dependency-free Python library for the
Chainway UR4 fixed UHF RFID reader.

**Library**
- `UR4Client` (TCP command channel): version, temperature, work mode, network
  settings, UDP destination, antennas, power, region, GPI/GPO, beep, trigger
  parameters, RF link, Gen2, inventory mode, antenna dwell time
- Continuous inventory: `async for tag in reader.inventory(duration=…)`. Stop is
  always sent, including on `break`, exceptions and cancellation.
- Guarded network-changing commands (`set_network_config`,
  `set_udp_destination`, `factory_reset`) need `confirm=True`
- `UR4UdpListener` for auto/trigger mode, with per-source decoding, source
  filtering, stats and async iteration
- `TagPresence`: bounded, clock-injectable presence tracking
- `provision()`: ordered auto-mode setup with dry run
- `discover()`: passive listener for reader announcements on UDP 1111

**CLI:** `aiochainway` with `info`, `inventory`, `listen`, `provision`,
`decode`/`encode` and more; `--debug` shows every frame in hex.

**Docs:** protocol write-up with per-command source and status, macOS bring-up
guide, hardware validation checklist, notes for the pantry integration.

**Status:** every command layout is taken from Chainway's SDK (`sdk-derived`)
except where noted. Nothing has been verified on hardware yet.
