# v0.2.0: Ship the fake reader as aiochainway.testing

**New:** `aiochainway.testing`, the in-process fake UR4 that this library's own
tests use, is now part of the package so downstream projects (the pantry
Home Assistant integration) test against the fake from the same pinned version.

- `FakeUR4`: a TCP fake of the command port. `async with FakeUR4() as fake:`
  listens on 127.0.0.1 on a free port. `state`, `faults`, `tags`,
  `received`, `names()`, `wait_for()`, `drop_connections()`.
- `Faults`: delays, dropped/duplicated replies, corrupted XOR, partial and
  byte-by-byte writes, unsolicited tag frames, failure statuses, wrong
  sub-command echoes, disconnects (on a command or mid-inventory).
- `tag_record()` builds a `0x83` tag payload; `tag_frames()` builds the bytes
  of an auto-mode UDP datagram.
- CI checks that the fake answers every command the UR4 supports with a reply
  the client's own parsers accept, and that its command table matches the
  protocol registry. So the fake can't drift from the protocol.

No changes to the client, listener or protocol. Standard library only, as before.

Not affiliated with Chainway.
