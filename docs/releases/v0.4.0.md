# v0.4.0: Reader config enforcement; no antenna detection on the UR4

**`UR4Client.ensure_config(antennas, power_dbm, *, save=True)` → `ConfigResult`**
- Reads the antenna mask and per-antenna power and writes only what differs:
  the antenna mask with the save flag, then power for each requested antenna.
  Then reads back and verifies.
- `ConfigResult`: `changed`, `before`, `after`, `writes` (command,
  description, frame hex), `verified`, `mismatches`, `dry_run`.
- `ValidationError` for an empty set, ports outside 1–4, or power outside
  1–30 dBm, raised before anything is sent. Never called implicitly.
- `dry_run=True` plans without writing. `save=False` sends the antenna flag
  `0x00`, which is inferred (the SDK only sends `0x01`), and needs
  `allow_unverified=True`.
- New `read_config()` returns a `ReaderConfig` (antennas + power).

**Antenna detection:** searched the whole SDK (every class's signatures and
string constants, plus the UR4 command classes and the C# demo). The UR4 has
**no** antenna-detect, return-loss, VSWR or connection-state command. Nothing
was invented; this is documented in `docs/protocol.md` §4.5. Hardware
validation §F.2 records whether an empty port shows up in any other way.

**CLI**
- `aiochainway config --antennas 1,2 --power 27 [--dry-run|--confirm]`, with
  the same guard rules as `provision`: neither flag means exit 5. Exit 4 if the
  read-back doesn't match.
- `aiochainway antennas` now prints the mask, per-antenna power and the
  detection status (`unsupported`). Its `--json` output changed to
  `{"antennas": [...], "power": {...}, "detection": "unsupported"}`.

**FakeUR4**
- Settings written with the save flag survive `await fake.power_cycle()`;
  others revert. Factory defaults are antennas 1–4 at 30 dBm, also restored by
  factory reset (`0x74`).
- New fault `ignore_writes`: a write is acknowledged but not applied.

**Docs:** hardware-validation §F (mask/power persistence across a power cycle,
including the inferred `00` flag; antenna detection observations), and
config enforcement in the integration notes.

**Protocol:** `28 00 hi lo` (set antennas, don't save) added as **inferred**.
No other changes.
